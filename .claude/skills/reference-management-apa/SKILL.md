# Reference Management (APA 7th Edition)

Create properly formatted reference lists following APA 7th edition guidelines.

## When to Use

- Creating reference lists for manuscripts
- Formatting individual citations
- Organizing references alphabetically
- Adding DOIs and URLs
- Converting references between formats

## Related Skills

- **citation-needed-check**: Identify where citations are needed, then format them here
- **due-diligence-research**: Find sources, then format them here
- **data-honesty-check**: Verify all references are real and accessible
- **scoping-review-methodology**: Reference lists for systematic reviews

## APA 7th Edition Basics

### Journal Article (Standard)
```
Author, A. A., Author, B. B., & Author, C. C. (Year). Title of article.
    *Journal Name*, *Volume*(Issue), Page–Page. https://doi.org/xxxxx
```

**Example:**
```
Smallwood, R. F., Potter, J. S., & Robin, D. A. (2016). Neurophysiological
    mechanisms in acceptance and commitment therapy in opioid-addicted
    patients with chronic pain. *Psychiatry Research: Neuroimaging*,
    *250*, 12–14. https://doi.org/10.1016/j.pscychresns.2016.03.001
```

### Journal Article (21+ Authors)
List first 19 authors, ellipsis, then final author:
```
Author, A. A., Author, B. B., ... Author, Z. Z. (Year). Title.
    *Journal*, *Vol*(Issue), Pages. https://doi.org/xxxxx
```

### Book Chapter
```
Author, A. A. (Year). Title of chapter. In E. E. Editor (Ed.),
    *Title of book* (pp. xx–xx). Publisher. https://doi.org/xxxxx
```

### Edited Book
```
Editor, A. A. (Ed.). (Year). *Title of book*. Publisher.
```

### In Press / Forthcoming
```
Author, A. A. (in press). Title. *Journal Name*.
```

## Formatting Rules

### Authors
- Last name, First initial. Middle initial.
- Use & before final author
- Up to 20 authors: list all
- 21+ authors: first 19 ... last

### Year
- In parentheses after authors
- Use (n.d.) if no date
- Use (in press) if accepted but not published

### Title
- Article titles: Sentence case, no italics
- Journal names: Title Case, *italics*
- Book titles: Sentence case, *italics*

### Volume/Issue/Pages
- Volume in italics: *25*
- Issue in parentheses, not italic: (3)
- Page range with en-dash: 123–145
- Online-only: Article number instead of pages

### DOI
- Include when available
- Format: https://doi.org/xxxxx
- No period after DOI

## Reference List Organization

### Alphabetization
1. By first author's last name
2. Same author: chronological (oldest first)
3. Same author, same year: a, b, c suffix

### Example Order
```
Aytur, S. A., ... (2021).
Cho, S.-E., ... (2025).
de Leon, J., ... (2005).
Fan, L., ... (2025).
```

### Handling Prefixes
- de, van, von: Alphabetize by prefix
- "de Leon" under D
- "Van Haren" under V

## Common Corrections

### Missing Elements
| If Missing | Solution |
|------------|----------|
| DOI | Provide URL if available |
| Issue number | Omit parentheses |
| Page numbers | Use article number |
| Author | Start with title |

### Format Fixes
| Wrong | Correct |
|-------|---------|
| Vol. 25 | *25* |
| pp. 12-14 | 12–14 |
| doi: 10.xxx | https://doi.org/10.xxx |
| Retrieved from | [omit, just use URL] |

## Quality Checklist

Before finalizing reference list:
- [ ] Alphabetized correctly
- [ ] All authors formatted consistently
- [ ] Journal names italicized
- [ ] Volume numbers italicized
- [ ] DOIs included where available
- [ ] No periods after DOIs
- [ ] Page ranges use en-dash (–)
- [ ] Hanging indent applied (if formatting)
- [ ] All in-text citations have reference
- [ ] All references cited in text

## In-Text Citations

### One Author
(Smith, 2020) or Smith (2020)

### Two Authors
(Smith & Jones, 2020) or Smith and Jones (2020)

### Three+ Authors
(Smith et al., 2020) or Smith et al. (2020)

### Multiple Citations
(Jones, 2019; Smith, 2020; Wang et al., 2021)

### Page Numbers (Direct Quote)
(Smith, 2020, p. 15)

## Special Cases

### Systematic Review Already Published
If citing from another review:
> "Six studies identified by Koster et al. (2025)..."

### Unpublished/In Press
```
Musket, C. W., et al. (in press). Title. *Journal*.
```

### Preprint
```
Author, A. A. (Year). Title. *PsyArXiv*. https://doi.org/xxxxx
```

## Guidelines

- Verify DOIs work before finalizing
- Use official journal names (check website)
- Include all authors up to 20
- Don't abbreviate journal names in reference list
- Keep reference list as single consolidated section
- Remove duplicate references before finalizing
