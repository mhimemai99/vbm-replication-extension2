# Academic Prose Writing

Transform draft content into polished academic prose suitable for peer-reviewed journals.

## When to Use

- User says writing looks "AI-like" or "unprofessional"
- Content has too many bullet points or numbered lists
- Sections have fragmented structure with many subheadings
- Writing uses bold/italic for emphasis excessively
- Text sounds promotional rather than scholarly

## AI-Like Patterns to Eliminate

### Structural Patterns
- Excessive bullet points
- Numbered lists where paragraphs suffice
- Bold labels (`**Population**:`, `**Concept**:`)
- Horizontal rules (`---`) between sections
- Too many subheadings (### for every paragraph)
- "Summary" sections with numbered takeaways

### Language Patterns
- Starting with "Here's" or "Let me"
- "This is important because..."
- Superlatives: "crucial", "critical", "essential"
- Promotional: "novel", "groundbreaking", "comprehensive"
- Hedging stacks: "may potentially possibly suggest"
- Repetitive emphasis on the same point

### Formatting Patterns
- **Bold** for emphasis within paragraphs
- *Italics* for non-standard emphasis
- CAPS for emphasis
- Emoji (never in academic writing)

## Transformation Process

### Step 1: Identify Structure

Map the logical flow:
- What is the main point of this section?
- What sub-points support it?
- What is the natural progression?

### Step 2: Convert Lists to Prose

**Before (list):**
```
Eligibility criteria:
- Adults ≥18 years
- Diagnosed schizophrenia
- Smokers vs non-smokers comparison
```

**After (prose):**
```
Eligible studies included adults aged 18 years or older with
diagnosed schizophrenia who were compared by smoking status.
```

### Step 3: Consolidate Subheadings

**Before (fragmented):**
```
### Population
Adults with schizophrenia.

### Concept
Smoking and brain structure.

### Context
Cross-sectional studies.
```

**After (consolidated):**
```
## Eligibility Criteria

Eligibility criteria were developed using the Population,
Concept, Context framework. Eligible studies included adults
with diagnosed schizophrenia, examining smoking status in
relation to brain structure, using cross-sectional designs.
```

### Step 4: Remove Promotional Language

| Avoid | Use Instead |
|-------|-------------|
| novel | - (just state what it is) |
| comprehensive | thorough, systematic |
| crucial | important |
| groundbreaking | - (let readers judge) |
| demonstrates | suggests, indicates |
| proves | supports, is consistent with |

### Step 5: Add Appropriate Hedging

Academic writing acknowledges uncertainty:
- "may" instead of "will"
- "suggests" instead of "shows"
- "is associated with" instead of "causes"
- "appears to" instead of "is"

But avoid over-hedging:
- Bad: "This may potentially suggest a possible relationship"
- Good: "This suggests a relationship"

## Section-Specific Guidelines

### Methods
- Use past tense
- Be specific but not verbose
- Cite methodological sources
- No results or interpretation

### Results
- Report findings, not interpretations
- Use tables to support (not replace) text
- Acknowledge contradictory findings
- Be precise with statistics

### Discussion
- Interpret, don't repeat results
- Compare with prior literature
- Acknowledge limitations honestly
- Avoid overclaiming

## Example Transformation

**Before:**
```
## The Double Gap

This review identifies two related gaps:

**Gap 1: fMRI literature has no structural component.**
All 4 fMRI studies examining psychological flexibility
used functional imaging. Zero examined whether psychological
flexibility relates to brain structure.

**Gap 2: sMRI literature has no psychological flexibility
measures.** All 8 sMRI studies measured smoking status and
brain structure, but none included the AAQ-II.
```

**After:**
```
## Gaps in the Literature

This review identifies two complementary gaps. First, the
functional neuroimaging literature on psychological flexibility
lacks any structural component. All four fMRI studies examined
brain function, but none assessed whether psychological
flexibility relates to gray matter volume or cortical thickness.
Second, the structural neuroimaging literature on smoking in
schizophrenia lacks psychological flexibility measurement.
All eight sMRI studies characterized smoking status and brain
structure, but none included the Acceptance and Action
Questionnaire-II or related measures.
```

## Guidelines

- Read published papers in target journal for style models
- One idea per paragraph
- Topic sentence first, then support
- Transitions between paragraphs
- Vary sentence length and structure
- Be concise but not telegraphic
